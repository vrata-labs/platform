# Public Demo Materials

The agenda text and the PDF text and vector graphics generated by `tools/public-demo.mjs` are original VRATA project materials distributed under the repository's Apache-2.0 license.

The PDF is generated with `pdf-lib` 1.17.1, distributed under the MIT license. It uses PDF standard Helvetica fonts and does not embed third-party images or font files.

The demo room uses the existing `meeting-room-basic@2.0.0` template and its pinned `warm-modern-meeting-room-candidate-01@0.3.4` scene release from `vrata-labs/warm-modern-meeting-room-candidate-01`, commit `a237ab799acbee3932846147c9f48bf1d1b4aaa8`. No scene asset is copied into these fixtures; its provenance and license remain defined by that published scene release.
