Проверка изоляции плагинов

Для опасных сценариев состояние плагина failed ожидаемо: он должен быть остановлен. Результат самой проверки показан отдельно — PASS или FAIL.

Ручная проверка на Quest или Windows

Откройте эту страницу отдельно на каждом устройстве. Нажмите «Проверить все сценарии» и сразу нажмите кнопку отклика ПОКА ИДЁТ прогон. Не скрывайте страницу. Клик после завершения не подтверждает отклик во время нагрузки — в таком случае повторите прогон. Затем скачайте отчёт этого браузера.

Даже PASS полной диагностики не закрывает весь device gate. Здесь проверяется браузерная изоляция; полноценные комнатные и VR-функции требуют отдельной проверки.

Контрольный плагин пингуется параллельно каждой опасной операции с периодом не чаще 250 ms. Для операций от 500 ms нужен ACK до их завершения. Короткие операции запускают concurrent ping и дожидаются его ACK. Дополнительно проверяются ответы после каждого сценария.

Результаты по сценариям

    Как читать результат

    PASS + failed у опасного сценария означает, что изоляция сработала. FAIL означает неожиданный код, незавершённый экземпляр, принятый опасный status или другое несовпадение ожиданий.

    Для зависающего native-вызова регулярного выражения допустимы прерывание VM или уничтожение Worker watchdog. Ошибка загрузки WASM либо boot timeout не являются успешной проверкой опасного сценария.

    Проверяется также фаза: init, event, dispose или complete. Например, отказ на init не означает, что пройден сценарий зависшего event. Незавершение import-программы не доказывает import_denied: сетевую/CSP-изоляцию подтверждает отдельный автоматический тест.

    Quest/ARM и Windows могут отличаться скоростью запуска, реализацией браузера, планированием задач и текущей нагрузкой. Поэтому фиксируются User-Agent, фаза, время, RAF gaps и input delay. Неожиданный timeout обычного плагина — красный FAIL, а не допустимое поведение. Бюджет VM 50 ms сохраняется; сравнивайте прогоны без посторонней нагрузки, не скрывая ошибку предыдущего отчёта.

    Размер WASM buffer — не вся память браузера. Подсказки memory_exhausted и stack_exhausted ограничены по размеру, но остаются недоверенными данными исключения.

    В отчёте — только результаты фиксированных сценариев, выбранный тип устройства, User-Agent и размер окна. Он не содержит комнатного контекста, токенов, cookies или исходников плагинов.
