# Room plugin SDK 0.1.0

Immutable pnpm tarball for external plugin authors.

- File: vrata-room-plugin-sdk-0.1.0.tgz
- SHA-256: c301002fb1fdbd3eb1c4aad396adef4e0160d450051f1a3ee5e9ae84b66a7896
- Package: @vrata/room-plugin-sdk@0.1.0
- License: Apache-2.0
- Node.js: >=22

Copy the tarball into a standalone sample directory before installing its
dependencies. Both included samples use a local-file SDK dependency; they do
not resolve the unpublished SDK name through an arbitrary public registry.

The installed vrata-room-plugin command bundles local JS/TS, packs an artifact
with the shared validator and validates exact bytes. The archive includes
welcome-status and auto-seat sources, manifests, bundled entries and artifacts.
Live auto-seat execution still needs the platform broker and seating adapter.
