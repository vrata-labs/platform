# Объёмный круглый маркер сидячего места

## Задание и границы

База: `8004b687c1e6e8eaf235e72fa3ebe8fbbe210b54`.
Применены `docs/scene-quality-contract.md` (редакция 2026-09-21) и структура
`scene-authoring-task-template.md`. Это интерфейс поверх существующей мебели,
а не новая сцена. Освещение, мебель, манифесты, серверный протокол и движение
аватара не меняются. Пользователь разрешил подготовку и слияние PR после проверок.

Согласованный эталон: круглый полупрозрачный объём с верхним диском, соединённой
боковиной, основанием, тонкими ободками и симметричным шевроном. Стрелка показывает
базовое направление лица после посадки, от спинки к переднему краю. Разнесённая
иллюстрация объясняет устройство; в приложении части соединены без воздушных
зазоров. Это проект VRATA, не доказательство точного вида оригинального Sense Tower.

| Параметр | Значение |
| --- | --- |
| Внешний диаметр | 0,44 м, независимо от радиуса взаимодействия |
| Высота | 0,14 м |

| Верхняя кромка | 0,015 м внутри общей высоты |
| Ободок | 0,004 м |
| Ширина стрелки / отступ над верхом | 0,14 / 0,003 м |
| Переход подсветки | 0,15 с, по времени, без движения и масштабирования |

Это параметры нового дизайна, не измерения Sense Tower. Голографический материал
и отсутствие физической опоры — явные исключения для интерфейса, не для мебели.

## Требования и сценарии

| ID | Применимость и проверка |
| --- | --- |
| Q1 | Объём и стрелка: реальные WebGL-снимки сверху, сбоку, под углом, на светлом и тёмном фоне; отдельно кадры полного приложения. Файл снимка не равен визуальной приёмке. |
| Q2 | Маркер обозначает конкретное место. Острие геометрии проверяется относительно настоящей камеры, ориентированной существующим контроллером посадки. |
| Q3 | Соединение верха, боковины и основания, зазор над сиденьем, отсутствие двойного прибавления seatHeight. Поддержка голограмме не нужна. |
| Q4 | Центральный и косой луч, реальное серверное подтверждение, наблюдение вторым клиентом, освобождение и повторное появление. |
| Q5 | Собственное и занятое места скрыты, но занятая цель не пропускает луч к полу. Выход из места и переход на другое место сохраняются. |
| Q6 | Панорамы и наружное окружение не изменяются. |
| Q7 | Единое представление для всех мест. Эталон мебели — принятая Warm Modern Meeting Room 0.3.3, 5580a7b080cf6195e28ebc77b654fd71111b0cd1. |
| Q8 | Реальные комнаты с соседними креслами; расстановка не изменяется. |

Роли проверки: пользователь выбирает место центральным лучом и видит направление;
сборщик проверяет соединённые поверхности; физическая проверка проверяет размеры,
привязку над сиденьем и неизменность мебели. Это не повторная приёмка всей комнаты.
Для браузерных проверок берутся неизменённые текущие поставки Meeting 0.3.4 и
Presentation 0.4.2 из штатного контракта шаблонов.

## Устройство и проверки

Геометрия разделяется внутри контроллера, материалы состояния индивидуальны.
`clear/rebuild` освобождают собственные ресурсы и сохраняют ссылку `hitMeshes`.
Нет новых зависимостей, текстур, света, обязательного bloom или покадрового
создания материалов. Проверка глубины включена; боковина имеет градиент по высоте.

Невидимый цилиндр выбора помечается `seatMarkerBlocked` из передаваемого снимка
`currentSeatId/occupancy`. Это производный признак для разрешителя целей, не
резервирование. Штатный `syncSeatStateFromOccupancy` сразу обновляет представление.
Занятый коллайдер сохраняется; также проверяется существующая радиальная область
и принудительная диагностическая цель. Авторитетное занятие приоритетнее наведения.

Автотесты: `seat-marker-view.test.ts`, `seat-marker-targets.test.ts`,
`tests/e2e/seat-marker-visual.spec.ts`. Последний сохраняет отдельные компонентные
и полноценные браузерные снимки в стандартные артефакты Playwright. В реальной
комнате выбор проходит через центральный указатель и подтверждение, не через
принудительную подмену занятости. Второй клиент проверяет серверное состояние.

## Статус доказательств

На момент отправки первого коммита: DRAFT, ожидает полного PR CI и просмотра
браузерных кадров. Прямое клонирование в среде подготовки недоступно из-за DNS;
локальная синтаксическая проверка не выдаётся за полную сборку. Ветка и запись
Git восстановлены через штатное подключение GitHub. Результаты CI, просмотр
кадров и проверка развёрнутого SHA фиксируются в PR с идентификаторами запусков.
Проверка физического шлема не проводилась и не подменяется браузерной эмуляцией.
