## Причинные границы auto-seat

1. **Admission до readiness.** `firstReady` запускает entry20000, а не начало Node setup. D-078 заменяет post-ready discovery barrier: четыре формы ждут до admission; дальше normal native transport/discovery/startup не удерживаются. Actual-component control отличает post-ready discovery hold20001 (entry-expired, claim0) от ожидания25000 до admission (полный entry budget). Старые неполные failure traces этим задним числом не объясняются.
2. **Native receive не app delivery.** Actual Playwright mock control различает native400/app3500. Passive ACK observer и adapter diagnostics коррелируют текущие generation/attempt и непосредственное consumption; dispatch, handler-generated request и promise completion не взаимозаменяемы. Initial transport без proxy; управляемый pending replay остаётся отдельным witness.
3. **Независимый pending case.** Local/X используют один export и общий external build/ordinary Host CAS. Host renderer закрыт; во время pending один3D entrant. Normal startup без discovery hold bounded60000 после scene+connection entry, response15000 начинается при actual outgoing claim. Pre-send page-clock facts обязаны подтвердить pending/standing, readiness/correlation/online, activation≤entry20000 и claim<arrival5000. Поздняя instance не исправляет эти факты.
4. **Disable causality.** CAS начинается в correlated actual accepted callback; pending refresh продолжается после CAS200, без fabricated response/kick. Runtime обязан принять именно CAS revision, HTTP200/empty bindings и settlement retired; ровно один claim/release, Node и browser release<3000. У свежей единственной claim instance sticky lastInstanceFailure=null: VM failure тоже вызывает retire, а последующий empty manifest скрывает failed entries/lastFailure. Actual-helper/component negative control воспроизводит именно этот контрпример.
5. **Intermediate, не final-only.** Observer считает реальный app mock dispatch, не CDP/native upstream. Сначала удержанные occupied+accepted, delivery counters и два RAF, затем current+pending=null/desktop/unchanged root. Лишь после этого empty/release в исходном порядке, correlated release и fresh exact authority. Controls release3200/entry21050 сохраняют отказ.
6. **Disabled late entrant.** До закрытия контекста обязательны настоящий runtime HTTP200 с ожидаемой CAS revision и empty bindings, принятая runtime state=empty/revision/instances0/running0/failed0, workers0/wasm0/claims0/current+pending=null и authoritative empty occupancy/exact single participant. Controls с незавершённой discovery и непринятой revision отвергаются. Без фиксированного sleep.

## Обязательный DoD

Точные команды и environment guards находятся в [JSON](2026-10-31-t16-regression.json). Нужны Node22, frozen dependencies/Chromium, настоящий собственный PG16; flags Playwright ставятся до file regex. Build требуется до compiled tests и при изменении соответствующих apps/packages.

Окончательное дерево проходит focused-unit/browser, package-checks и **нефильтрованный final-full-local**, затем все exact-SHA внешние критерии. При executable fixes final full повторяется; failed/skipped/stale не превращаются в passed. Не менять scope-документы во время проверок.

Published G/X предпочтительно подтверждаются обычными workflows и их artifacts на том же commit, без второго дублирующего полного запуска. Нужны active reference catalog, фактический floor2 и неизменные accepted/images до/после X. Scoped T16 PASS не делает весь X зелёным. После проверки — independent owned cleanup, release собственной lease и конечная фаза; T17 остаётся открыт.
