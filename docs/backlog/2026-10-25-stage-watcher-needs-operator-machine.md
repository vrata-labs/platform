# Забытый стенд удаляется, только пока работает машина разработки

## Что не так
Уборщик стенда — фоновый процесс `vrata-stage reap` на машине разработки. Если машина выключена или WSL остановлен, истёкшие аренды никто не обрабатывает, и стенд оплачивается до следующего запуска любой команды `vrata-stage`. Срок аренды ограничен сутками, но после истечения срока удалять стенд некому.

## Почему всплыло
Учётные данные Selectel есть только локально, поэтому создание и удаление сознательно сделаны на машине разработки. Ограничение записано в плане `docs/plans/2026-10-25-on-demand-stages.md`, раздел «Риски и откаты».

## Почему не сейчас
Внешний сборщик требует отдельной учётной записи Selectel с правами только на стенды, а это решение по доступам владельца.

## Что сделать
Решить, нужен ли внешний сборщик. Например, плановый workflow с отдельным сервисным пользователем в проекте только для стендов. Он удалял бы стенд с тегом `vrata-stage`, у которого истёк срок всех аренд и нет активных прогонов CI.

## Стоимость и эффект
Не оценено. Эффект — верхняя граница расходов на забытый стенд при выключенной машине разработки.
