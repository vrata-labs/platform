# Запрос теста portal-managed-grants к API иногда обрывается с socket hang up

## Что не так
`portal-managed-grants.spec.ts:55` («a portal grant opens one demo instance…») упал на `apiRequestContext.fetch: socket hang up` в хелпере запроса к фикстуре (`portal-managed-grants.spec.ts:43`). Сервер фикстуры закрыл соединение, не ответив. При повторе job тест прошёл.

## Почему всплыло
CI 40352361975, первая попытка job e2e (5), на PR #139, который этот тест не трогал. Повтор job прошёл.

## Почему не сейчас
Падение всплыло попутно, причина не разобрана. Неизвестно, падал ли процесс API фикстуры, закрывал ли он keep-alive соединение раньше клиента или это перегрузка раннера.

## Что сделать
По артефактам упавшего прогона выяснить, жил ли процесс API фикстуры в момент запроса и что он записал в журнал. Если процесс жив, проверить таймауты keep-alive сервера против повторного использования соединения в `request.fetch`.

## Стоимость и эффект
Не оценено. Затрагивает стабильность e2e на чужих PR. Если причина в сервере, то и integration API, которым пользуется портал.
